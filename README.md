# Virtual Coffee Machine

Small .NET MAUI Blazor Hybrid application.

It accepts supported coins, sells Cappuccino, Latte and Decaf, calculates change and optionally saves completed transactions to a database.

## Stack

C# · .NET 10 · .NET MAUI · Blazor Hybrid · Razor · Supabase/PostgreSQL · xUnit

## Projects

- `CoffeeMachine.Core`: business rules and local machine state.
- `CoffeeMachine.Maui`: Windows/Android application and Supabase integration.
- `CoffeeMachine.Tests`: xUnit tests for the business logic.
